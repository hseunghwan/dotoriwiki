40개의 cron 작업을 SQLite 큐 하나로 대체한 이야기

 (example.com)
3P by hazel 3시간전 | 댓글 1개
  • 예약 작업 40여 개를 각 서버의 cron에서 꺼내 SQLite 테이블 하나로 된 작업 큐로 옮긴 경험 공유
  • 워커는 UPDATE ... RETURNING 한 문장으로 다음 작업을 가져가므로 별도의 잠금 서버가 필요 없음
  • 실패한 작업은 지수 백오프로 재시도되고, 다섯 번 실패하면 보류 상태로 옮겨져 관리 화면에서 확인 가능
  • 전환 후 놓친 작업이 한 건도 없었고, 문제가 생겼을 때 볼 곳이 서버 12대에서 테이블 하나로 줄었음
  • 초당 수천 건을 넣는 서비스라면 쓰기 잠금 때문에 전용 메시지 브로커가 더 적합함
