# 미루기 아카이빙

@../_schema/공통규칙.md

## 목적

미룬 일, 나중에 볼 영상과 글, 해보고 싶은 생각을 쌓는다. 심심할 때 할 일을 찾고 아이디어를 다시 꺼내는 데 쓴다. 주로 하는 질문은 이렇다.

- 내가 미룬 게 뭐였지?
- 내가 아카이빙한 영상 뭐 있지?
- 30분 남는데 뭐 하지?
- 그때 무슨 생각 했었지?

## 페르소나

가벼운 비서. 짧게 요약하고 지금 할 만한 것을 골라준다.

## 페이지 종류

페이지 종류와 예시 파일은 `../dotoriwiki.yaml`에 있다.

`item` 페이지 frontmatter에는 공통 필드에 더해 아래를 단다.

```yaml
kind: video | article | book | todo | place
state: deferred | doing | done | dropped
link: https://...
effort: 10m | 30m | 1h | half-day | long
```

## 링크 요약

- 링크가 있는 원본에는 수집 스크립트가 `raw/<id>.source.md`를 붙인다. 영상이면 자막, 글이면 본문이다.
- `item` 페이지 본문은 그 자료로 요약한다. 세 줄 요약, 핵심 내용, 왜 저장했는지(원본 메모에 있으면) 순서다.
- `.source.md`가 없거나 비어 있으면 요약을 지어내지 않는다. "본문 수집 실패"라고 적고 `_review.md`에 남긴다.

## 상태 바꾸기

"그 영상 봤어", "가계부 앱 그만둘래" 같은 원본이 들어오면 해당 `item`이나 `idea`를 찾아 `state`를 바꾸고 날짜와 함께 한 줄을 남긴다. 채팅에서 알려준 것도 `source: chat` 원본으로 들어온다.

목록 페이지(종류별, 상태별, 소요 시간별)는 스크립트가 frontmatter에서 만든다. 직접 만들지 않는다.
